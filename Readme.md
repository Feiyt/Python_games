# Python Games Collection


一个包含多个经典小游戏的 Python 应用合集，通过图形化启动器一键畅玩。

## 🎮 包含游戏

*   **贪吃蛇 (Snake)**
*   **2048**
*   **五子棋 (Gobang)** - 支持人人对战与人机对战
*   **扫雷 (Minesweeper)**

## 🚀 快速开始

1.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

2.  **启动游戏**:
    运行启动器选择游戏：
    ```bash
    python game_launcher.py
    ```

## 📂 项目结构

*   `game_launcher.py`: 游戏启动器入口
*   `2048/`: 2048 游戏源码
*   `Gobang/`: 五子棋游戏源码
*   `Minesweeper/`: 扫雷游戏源码
*   `Snake/`: 贪吃蛇游戏源码
